# 💬 MERN ChatConnect

A real-time chat application built using the MERN stack with Socket.IO. Users can register, log in, join groups, send messages in real time, and manage their profiles.

## 🚀 Live Demo

🌐 Frontend: # 💬 MERN ChatConnect

A real-time chat application built using the MERN stack with Socket.IO. Users can register, log in, join groups, send messages in real time, and manage their profiles.

## 🚀 Live Demo

🌐 Frontend: https://mern-chat-omega-six.vercel.app/

🔗 Backend: https://mern-chat-backend-klnv.onrender.com/

## ✨ Features

- 🔐 User Registration & Login
- 🔑 JWT Authentication
- 👥 Group Chat
- 💬 Real-time Messaging
- ⚡ Socket.IO Real-time Communication
- 👤 User Profiles
- 🖼️ Profile Pictures
- 🛡️ Protected Routes
- 👑 Admin Group Management
- ✏️ Message Management
- 📱 Responsive UI
- ☁️ Cloudinary Image Storage
- 🗄️ MongoDB Database

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router
- Chakra UI
- Axios
- Socket.IO Client
- Vite

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- Socket.IO
- JWT
- bcryptjs
- Cloudinary

### Deployment
- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas
- Images: Cloudinary
